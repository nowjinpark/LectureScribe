처음 사용하기 전에

  • 설치 위치는 응용 프로그램 → 강의노트입니다. 기존 강의 파일과 음성 모델은 설치 대상에 포함되지 않습니다.
  • 처음 텍스트로 변환할 때 약 630 MB의 음성 모델을 내려받습니다. 인터넷 연결과 추가 저장 공간이 필요합니다. 이후 음성 변환은 Mac 안에서 처리합니다.
  • Zoom 소리를 녹음하려면 macOS의 화면 및 시스템 오디오 녹음 권한을 허용해야 합니다. 허용 후 앱을 완전히 종료하고 다시 열어 주세요.
  • 현재 공개 배포본은 Apple Developer ID 서명·공증이 없어 최초 실행 시 macOS 보안 허용이 필요할 수 있습니다.
