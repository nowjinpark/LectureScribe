# 화면 사진

이 폴더는 실제 강의노트 앱 창에서 촬영한 공개용 JPEG를 보관합니다.

- `summary.jpg`: 한국어 합성 음성을 앱에서 전사한 뒤 Apple Intelligence가 생성한 요약.
- `transcript.jpg`: 같은 합성 음성의 실제 인식 결과와 시간 정보. 오인식도 그대로 표시합니다.
- `recording-setup.jpg`: 예제 제목을 입력한 녹음 설정 화면. 촬영을 위해 녹음을 시작하지 않았습니다.

실제 수업, 참가자 정보, 계정 정보, 개인 문서와 절대 파일 경로는 포함하지 않았습니다. 화면의 `ui-smoke`는 검증용 작업 폴더 이름입니다.
